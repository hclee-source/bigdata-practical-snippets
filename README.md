# 빅데이터분석기사 실기 파이썬 스니펫

『2027 빠르게 따는 빅데이터분석기사 실기』(골든래빗) 부속 자료.
작업형 1·2·3에 쓰는 파이썬 코드 **75개**를 모았고, 감점이 자주 나는 **12개**에는
노란 형광펜으로 「함정·필수·빈출」 표시를 붙였습니다. 코드는 교재 풀이의 관례
(`prepare_features`, `reindex(fill_value=0)`, `classes_`로 양성 확률 위치 찾기,
`Logit(...).fit(disp=False)` 등)를 그대로 따릅니다.

공개 주소: **https://hclee-source.github.io/bigdata-practical-snippets/**

필기 편: [빅데이터분석기사 필기 공식집](https://hclee-source.github.io/bigdata-formulas/)

**카카오톡은 상대 경로 `og:image`를 읽지 못해서**입니다. 저장소명이나 도메인을 바꾸면
`build.py` 의 이 세 줄과 `verify.py` 의 `BASE` 를 같이 바꿔 주세요.

## 내용을 고칠 때

1. `cards.py` — 스니펫 코드·제목·태그·검색어 / `when.py` — 「언제 쓰나」 한 줄
2. `python build.py` — `index.html` 을 다시 만든다
3. `python verify.py` — 아래를 한 번에 검사한다 (pandas·numpy·scikit-learn·scipy·statsmodels·Pillow 필요)

| 검사 | 내용 |
|---|---|
| 스니펫 실행 | 75개 코드를 가짜 데이터로 **전부 실제 실행**. 준비 코드는 데이터만 만들고, import·함수는 **화면 순서대로 앞 카드에서 정의된 것만** 이어받는다 — 화면의 import 줄을 지우면 실패한다 |
| 주석 검산 | 주석에 쓴 주장 11건을 숫자로 확인 — `int()` 버림 방향, `round` 의 .5 처리, sklearn 로지스틱(newton-cholesky, tol=1e-8) = statsmodels `Logit` 넷째 자리까지(데이터 20벌), 2×2 연속성 보정, `alternative` 방향, `zscore` ddof, `concat(axis=1)` 은 행 번호로 붙음 등 |
| 페이지 점검 | `index.html` = `build.py` 결과(**통째로**), 공유 카드 절대 주소, 아이콘 크기, 404 링크가 절대 경로인지 |
| 글자 대비 | 글자로 쓰이는 색 조합 전부(라이트·다크)가 WCAG AA(4.5:1) 이상. 색은 `#RRGGBB` 만 허용하고, 인쇄 색이 라이트와 같은지도 본다. `--faint` 는 0건으로 흐려진(비활성) 목차 링크에만 써서 예외 |

경고(폐기 예정 등)는 실패로 치지 않고 마지막에 모아 보여 줍니다.

**검사하지 않는 것** — 실행이 끝나는지만 보고, 카드마다의 결과값(예: 정렬 방향이 맞는지)은 보지 않습니다.
결과값은 위 주석 검산 11건만 숫자로 확인합니다.

### 시험장 버전으로 검증

## 색

색은 도서 표지에서 가져왔습니다 — 남색(`#2b2f9c`)은 탭·목차·체크·코드 키워드, 노랑(`#f5e400`)은
「함정·필수·빈출」 형광펜과 사이드바 책등 제목, 초록(`#1e7a37`, 표지 초록을 글자 대비 AA에 맞게 조금 어둡게)은
「외움」 표시에만 씁니다. 노랑은 흰 바탕에서 글자로 읽히지 않으므로 항상 바탕(형광펜)으로만 씁니다. 서체는 IBM Plex Sans KR ·
IBM Plex Mono 한 가족입니다. 색은 전부 CSS 변수라
`build.py` 의 `:root` 한 곳만 보면 됩니다. 다크모드는 `@media (prefers-color-scheme:dark)`
에서, 인쇄는 `@media print` 에서 같은 변수를 덮어씁니다. **색을 새로 넣으면 세 곳 모두에
넣고 `verify.py` 의 대비 목록에도 추가하세요.**

## 알아 둘 점

- 시험장 scikit-learn 은 1.2 이상이라 `LogisticRegression(penalty=None)` 을 씁니다. 다만 풀이법(solver)과 수렴 기준을 주지 않으면
  버전에 따라 계수가 넷째 자리에서 statsmodels 와 달라져서, 카드는 `solver='newton-cholesky', tol=1e-8` 을 함께 씁니다
  (1.2·1.9 에서 데이터 40벌 모두 넷째 자리 일치·경고 없음. newton-cg 는 1.2 에서 수렴 경고가 뜨고, 기본 lbfgs 는 넷째 자리가 어긋난다).
  scikit-learn 1.10 부터는 `penalty` 인자가 없어질 예정입니다(1.9 에서 경고).
- 스니펫은 교재 원본 데이터가 아니라, 같은 컬럼 구조의 가짜 데이터로 실행 검증합니다.
